# 旧加密档案兼容说明

作者已取消阅读密钥。当前本书与空母版采用直接文件模式，先读《正文直接读取.md》。不要求作者导入钥匙，不自动生成新钥匙或把新章重新封存。

现行正式入口是`book/state.json`及其引用的正文、记录、设定和路线；`vault/`仅保留历史。旧聊天中“公开state只是0章基线”的说法已经随实际迁移失效，不能覆盖现行进度。

`tools/private_book.py`保留为旧档案兼容工具。对尚未迁移、确有`book/private_storage.json`的旧工程，须先认证其指向的真实密文，再在作者要求直接读取时使用`publish-plain --key-file 旧钥匙路径 --author-request 作者实际指令`。这是旧数据的一次迁移操作；完成后网站与GPT都直接读取，后续不再需要钥匙。工具会核对当前密文、书籍身份、真实state、正文/记录哈希，保留候选和回看，并拒绝发布夹带的密钥。

迁移、正文、状态和索引必须同次提交。实际密钥文件仍不上传到公开仓库或写入网页；取消阅读密钥不等于公开旧密钥内容。
