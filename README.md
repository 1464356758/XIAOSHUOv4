# GPT小说系统 V4.1 · GitHub线上版

一个仓库一部小说。GPT负责创作、审阅与维护，GitHub保存正式状态，手机网页负责阅读章节、复制正文、导出TXT和查看当前任务。

**阅读器：[小说书架](https://xiaoshuo-v4-reader-7d26.qq1464356758.chatgpt.site)**。首次打开已连接本仓库；也可以添加其他公开小说仓库，再在书架切换。新站点为账号私有访问，仓库公开读取不需要密钥。

## 本书当前状态

仓库初始化后先等待作者选择平台，没有默认选题或正式章节。实时状态见`online/index.json`及网页；这段README不是进度数据库。

在当前GPT聊天发送：

```text
读取GitHub仓库 https://github.com/1464356758/XIAOSHUOv4 的AGENTS.md和启动新书.txt，接管当前真实状态。先让我选择平台，再核查现行官方规则和公开榜单，提出5—10个原创选题，等我选择。当前先不写正文。
```

你也可以直接说“我选番茄”或“我选起点”，GPT读取仓库后记录选择，再执行研究。候选题材保存后会显示在网页，选定编号后再做长篇规划。

## 手机网页的功能

- 粘贴GitHub仓库链接，加入本机书架并切换作品。
- 默认每60秒读取当前公开仓库的最新索引，支持手动刷新；显示实际更新时间，失败保留已读内容。
- 浏览和搜索已采用章节；正文版本核对后，一键复制本章、导出本章或整本TXT。
- 查看已完成章数、实测字数、当前任务、下一步、重要进度记录、平台研究和待选题材。
- 调节阅读字号和纸色。页面可由支持的手机浏览器添加到桌面。

网页不调用GPT模型。创作与规则研究仍由你当前的GPT任务执行，结果写回仓库后才成为线上进度。网页里的按钮会明确标注“复制指令”，不会假装已经触发模型。当前免密钥读取支持公开仓库；私有仓库需要另行授权服务端连接。

## 下一本小说

下载仓库中的`初始化系统包.zip`，将包内文件复制到新仓库的**根目录**。该包没有本书身份、正文、进度和研究。

把新链接和下面这段话发给GPT，完整版本也在包内《启动新书.txt》：

```text
请接管这个新小说仓库：在这里填新仓库链接。
读取AGENTS.md和启动新书.txt，使用空母版初始化，生成这本书的新身份。先让我选择平台，再查官方规则和榜单，给出5—10个原创选题等我选择。所有重要进度写回GitHub并更新online/index.json，当前先不写正文。
```

然后在同一个阅读器添加新仓库链接。无需为每一本小说重新部署网页。已有小说不要用空包覆盖，应先迁移和核对。

## 系统文件

| 文件 | 用途 |
| --- | --- |
| `AGENTS.md`、`启动新书.txt` | GPT接管与开新书 |
| `平台研究与选题.md` | 平台规则、扫榜和5—10候选的生成方法 |
| `book/state.json`、`book/workflow.json` | 采用版本与当前任务 |
| `online/index.json` | 网页读取的当前索引 |
| `research/` | 本书可回查的平台研究与候选版本 |
| `tools/novel_state.py` | 字数、版本、记忆、修订与回看 |
| `tools/online_state.py` | 初始化、平台、选题、任务与阅读索引 |
| `tools/make_init_package.py` | 生成不带本书数据的空母版 |
| `web/` | 阅读器源码与测试，可供维护和复用 |
| `docs/线上同步协议.md` | 同次提交、版本核对与同步边界 |

GPT操作示例：

```bash
python3 tools/online_state.py bootstrap --repo https://github.com/1464356758/XIAOSHUOv4
python3 tools/online_state.py select-platform --platform fanqie
python3 tools/online_state.py build-index
python3 tools/online_state.py validate-index
```

这些命令由具备文件与执行能力的GPT运行，不要求作者手工填写JSON。初始化有真实状态时会接管而不清空；正文采用遵循每章8000—10000汉字、最多3轮局部修订和每5章回看的默认设置。

机制验证见`docs/验证记录.md`。程序检查不能证明文学质量，真实作品仍需开篇和阶段阅读校准；不保证平台签约、收入或长篇永不出错。
